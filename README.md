# StreakBuddy
StreakBuddy is a streaksaver application based completely off of hackatime by the generous folks at hackclub. This application makes use of a hackatime data to show a clean and usable interface on the dashboard.

## Description
Streak buddy makes use of the Hackatime API developed by the folks at hackclub, to show users a simple UI that summarises their weekly work via a growing plant that grows with the hours that a user logs onto their hackatime account via the API and an approved editor. The app is windows only as i do not have access to a macos/linux pc at the moment

## Getting Started

### Dependencies

* dotenv
* express
* electron
* electron-builder

### Installing

* Install the latest release from the github releases on this repository
* Link your hackatime account through the settings page on the app
* Thats it!

### Executing program

* just run the setup.exe file on your windows computer, the installer takes care of everything that you need to do.
